# 🛠️ Implementation Plan: Option A - Logical Sub-Modules with Bundling

This document outlines the step-by-step implementation plan for refactoring `script.js` into sub-modules under `src/` while maintaining 100% backward compatibility with `file://` protocol execution and the `build_offline.py` build pipeline.

---

## 🎯 Architecture Overview

Option A splits `script.js` into focused domain-specific files inside a `src/` directory, and uses a zero-dependency Python script (`scripts/bundle_js.py`) to concatenate them into the single output `script.js` artifact required by `index.html` and `build_offline.py`.

```
IUPAC_Vocabulary_Project/
├── src/
│   ├── 01_constants.js    # CATEGORIES, FG_ATOMS, SVG icons
│   ├── 02_storage.js      # safeStorage helper
│   ├── 03_state.js        # Application state variables
│   ├── 04_dom.js          # Cached DOM element references
│   ├── 05_theme.js        # Theme management & 3Dmol check
│   ├── 06_filters.js      # Category counts and stats
│   ├── 07_render.js       # Card generation & list rendering
│   ├── 08_sidebar.js      # Molecule selection & detail pane
│   ├── 09_viewer.js       # 3Dmol & 2D SVG representation
│   ├── 10_snapshot.js     # PNG snapshots & canvas download
│   ├── 11_quiz.js         # Quiz engine & score tracking
│   ├── 12_utils.js        # Clipboard, toast, confetti
│   ├── 13_events.js       # All event listener setups
│   └── 14_init.js         # init() & DOMContentLoaded trigger
├── scripts/
│   └── bundle_js.py       # Concatenation bundler script
├── script.js              # Bundled distribution artifact (generated)
└── build_offline.py       # Embeds script.js into single HTML
```

---

## 📋 Step-by-Step Execution Strategy

### Step 1: Create `src/` Directory and Module Files
* Extract sections from `script.js` into numbered module files in `src/`.
* Preserve execution order so global variables and functions are declared before use.

### Step 2: Implement Zero-Dependency Bundler (`scripts/bundle_js.py`)
* Write a Python script to scan `src/*.js` in alphanumeric order, concatenate content with section headers, and write `script.js`.
* Update `build_offline.py` to trigger `bundle_js.py` automatically before packaging.

### Step 3: Automated Testing & Validation
* Run `pytest` to ensure `build_offline.py` and bundler behavior are tested.
* Run `python3 scripts/verify_data.py` to ensure data integrity.

### Step 4: Verification
* Verify that `script.js` is identical in behavior and passes all browser checks.
* Verify `IUPAC_Offline.html` generated by `build_offline.py` contains the complete script.

---

## 💡 Benefits

1. **Maintainability**: Individual files are 30-100 lines each.
2. **Zero Runtime Dependencies**: No npm, Webpack, or Babel required.
3. **`file://` & Offline Support**: Keeps `script.js` as a single file for browser compatibility without CORS issues.
